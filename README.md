# Weby & aplikace

Web [webyaplikace.cz](https://webyaplikace.cz/): tvorba webů a PWA aplikací na míru, Nela Mizera, MBA.

Statický web (HTML, CSS, JS), hostovaný na GitHub Pages.

- Stránky: `index.html`, `ukazky.html`, `sluzby.html`, `funkce.html`, `cenik.html`, `o-mne.html`, `kontakt.html`, `podminky.html`, `404.html`
- SEO: `sitemap.xml`, `robots.txt`, canonical a Open Graph v hlavičce každé stránky, strukturovaná data (ProfessionalService, Person, WebSite, FAQPage)
- PWA: `manifest.webmanifest`, `sw.js` (při změně souborů zvyšte verzi `CACHE`)
- Doména: soubor `CNAME`
